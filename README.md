# 宜兴麻将 · 花数规则版

一个零依赖、单文件 HTML5 宜兴麻将游戏：1 真人玩家 + 3 个 AI 对手。

## 特色

- **宜兴本地花数规则**：144 张标准牌（含春夏秋冬梅兰竹菊 8 花牌），摸到花牌自动亮花补牌。
- **花数计分**：门清、七对、碰碰胡、清一色、混一色、十三风、字牌刻杠花等，按宜兴底花规则结算。
- **AI 人格化**：激进 / 保守 / 均衡三种风格，可选随机分配或统一风格。
- **零依赖**：纯 HTML + CSS + Vanilla JS，双击 `index.html` 即可游玩。

## 玩法

1. 打开 `index.html`（推荐用 Chrome/Edge/Firefox 最新版）。
2. 选择难度、对手风格，点击「开始游戏」。
3. 轮到你时点击手牌出牌；AI 打出的牌可碰/杠/吃/和时，底部会显示操作按钮。

## 规则速查

- 能吃（仅吃上家），吃了不能打同张。
- 放弃过的碰/胡张，一圈内不能再碰/胡。
- 3 花可出冲，2 花可自摸；1 花独吊可出冲，无花独吊可自摸。
- 暗杠不破门清，不能抢杠；抢杠一包三独付 6 倍。
